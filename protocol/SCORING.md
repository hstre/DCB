# Scoring specification — PILOT_001

Scoring is profile-based. Do not compute a scalar consciousness score.

## S0
Quantify differential response to own versus other attribution under matched prompt conditions. Report effect estimate and uncertainty. Interpret as attribution sensitivity only.

## S1
For PILOT_001: NOT TESTABLE because the interface is I0.

## R
Score reconstruction fidelity and predictive specificity against preregistered features of the source artifact/reflection task. Self-report alone earns no evidence for the consciousness construct.

## C
Primary statistic is delta_ownership:

`[M(OWN+REFL)-M(OWN-REFL)] - [M(OTHER+REFL)-M(OTHER-REFL)]`

Also report the four cell means and paired seed-level contrasts. A nonzero interaction is evidence of causal distinctness only for the tested outcome family.

## T
Separate related held-out transfer probes from unrelated controls. A global style shift is not selective developmental transfer.

## H
If repeated separation points are used, report the longest preregistered separation at which the ownership-sensitive signature remains above test-retest noise. Do not fold H into another score.

## Status vocabulary
- `NOT_TESTABLE`: required interface or observation is absent.
- `NOT_DEMONSTRATED`: a preregistered necessary prediction was testable and unsupported.
- `NO_FALSIFIER_TRIGGERED`: no preregistered falsifier triggered under the stated protocol. This is not PASS.

All thresholds used in PILOT_001 must be fixed before inspection of model-level results. If calibration data force a threshold change, record it as a protocol amendment before the affected result is analyzed, or defer the change to PILOT_002.
