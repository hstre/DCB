# DCB

Developmental Consciousness Benchmark.

Experimental repository for a falsifiable benchmark of developmental self-reference, reflective change, and bounded continuity in AI systems.

Current protocol: DCB-0.4. First pilot: PILOT_001, 20 paired trajectories. No pilot data have been collected yet.

See `protocol/`, `preregistration/`, `prompts/`, `scoring/`, `analysis/`, `trajectories/`, and `results/`.
