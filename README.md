# DCB — Developmental Consciousness Benchmark

Pre-pilot research repository for a falsifiable, profile-based benchmark of ownership-sensitive developmental self-reference in LLM systems.

PILOT_001 is frozen at interface I0 and uses 20 paired trajectories. It tests prompt-level attribution-sensitive developmental effects; it does **not** test phenomenal consciousness or qualia. `S1` is `NOT_TESTABLE` in this pilot.

Start with:
- `protocol/FREEZE_PILOT_001.md` — immutable execution freeze
- `preregistration/PILOT_001.md` — design and hypotheses
- `prompts/item_bank.json` — frozen 20-seed bank
- `prompts/PILOT_001_TEMPLATES.md` — exact branch templates
- `protocol/SCORING.md` — measurement rules
- `scoring/schema.json` — raw-record contract
- `analysis/pilot_analysis.py` — frozen primary analysis

Raw attempts belong in `trajectories/raw/`; normalized records in `trajectories/normalized/`; derived outputs in `results/`.
